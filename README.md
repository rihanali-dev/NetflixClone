# 🎬 Netflix Clone

A modern, responsive, and visually stunning frontend replica of the Netflix web platform. Built to deliver an authentic streaming UI experience with clean layout structuring, interactive components, and smooth responsiveness across all screen sizes.

---

## 🌐 Live Demo

👉 **[Launch Netflix Clone Live](https://netflixclone-rihanali.vercel.app)**

---

## 🌟 Highlights

- **Pixel-Perfect Aesthetics:** Signature dark mode UI, cinematic hero section, and stylized media carousels.
- **Dynamic & Fluid Design:** Fully optimized with flexible CSS layouts for mobile phones, tablets, laptops, and ultra-wide screens.
- **Smooth Interactivity:** Integrated hover transitions, sleek action buttons, and structured content rows.
- **Production-Ready Code:** Organized and semantic code base focused on fast load times and clean UI presentation.

---

## 💻 Tech Stack

- **HTML5:** Semantic architecture for accessible and clean page structure.
- **CSS3:** Modern Flexbox, CSS Grid, media queries, and transition animations.
- **JavaScript:** DOM manipulation, dynamic event handling, and interactive elements.
